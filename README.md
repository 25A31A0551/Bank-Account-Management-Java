Bank Account Management System Using Java

A simple, console-based Bank Account Management System developed using Java. This project demonstrates Object-Oriented Programming (OOP) concepts, especially parameterized constructors, classes, objects, encapsulation, and methods.

Features

- Create a bank account with an account holder name, account number, and initial balance.
- Display account details.
- Deposit money.
- Withdraw money with balance validation.
- Check the available balance.
- Validate user inputs and handle invalid transactions.

Technologies Used

- Java
- Scanner class
- Object-Oriented Programming (OOP)

Concepts Covered

- Parameterized Constructor
- Classes and Objects
- Encapsulation
- Conditional Statements
- Loops and Switch Statements
- User Input Handling

How to Run

1. Save the source code as "BankManagement.java".
2. Compile using "javac BankManagement.java".
3. Execute using "java BankManagement".

Project Purpose

This project is designed for beginners to understand Java constructors and basic banking operations through a practical programming example.

Note: This is an educational project, not a real banking application. It does not include a database or permanent transaction storage.
